# ejecutar localmente
Para ejecutar el proyecto en local
1. Clona el repositorio y entra a la carpeta del proyecto
2. Crea un entorno virtual con python -m venv venv y si no se activa solo al abrir otra terminal, actívalo con venv\Scripts\activate
3. Después instala las dependencias con pip install -r requirements.txt
4. Ejecuta la aplicación con python app.py
5. Abre en el navegador la dirección http://127.0.0.1:5000
